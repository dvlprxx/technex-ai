# 🚀 TechNex AI Landing Page

**TechNex AI Landing Page** — AI xizmatlarini taqdim etish uchun yaratilgan zamonaviy va to‘liq responsive landing page. Ushbu loyiha AI servisning imkoniyatlari, afzalliklari va foydalanish yo‘riqnomalarini sodda va tushunarli tarzda ko‘rsatish uchun ishlab chiqilgan.

---

## 📌 Loyiha haqida

Bu landing page:
- AI xizmatni tanishtirish
- foydalanuvchilarga qulay interfeys taqdim etish
- startup yoki servisni professional ko‘rinishda namoyish qilish

uchun mo‘ljallangan.

Loyiha **faqat HTML va CSS** yordamida yozilgan, hech qanday framework ishlatilmagan.

---

## 🛠 Texnologiyalar

- **HTML5**
- **CSS3**
- JavaScript ishlatilmagan
- Frameworksiz (pure code)

---

## 📱 Responsive dizayn

Loyiha barcha qurilmalarda to‘g‘ri ishlashi uchun quyidagi breakpoint’larda moslashtirilgan:

- ≤ **1200px**
- **1024px**
- **768px**
- **480px** va undan kichik

## 🚀 Deploy qilish

Loyihani quyidagi platformalarda deploy qilish mumkin:

### GitHub Pages
1. Repository yarating
2. `index.html` root papkada bo‘lsin
3. **Settings → Pages** bo‘limiga o‘ting
4. Branch: `main`
5. Save qiling va linkdan foydalaning
